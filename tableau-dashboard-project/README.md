# Анализ выступлений на TED-конференциях в Tableau

**Ссылка на презентацию с интерактивными дашбордами:** https://public.tableau.com/app/profile/kamilla.nurgalieva/viz/Tableauproject_17287298135990/TED-?publish=yes

## Цель проекта
Проследить с помощью визуализаций, как менялись выступления на TED-конференциях на протяжении своей истории (с 2009 по 2021 год) 

**Источник данных:** материалы сайта TED (http://ted.com/)

**Что было сделано:** объединение исходных файлов, создание расчетных полей и построение визуализаций в Tableau" .

## Инструменты
Tableau

## Как пользоваться дашбордами
*   Используйте фильтры по периоду в левом верхем углу дашбордов "История выступлений", "Тематики выступлений","Авторы выступлений";
*   Выбирайте страны на визуализации "Выступления по странам" на дашборде "История выступлений", чтобы увидеть информацию по выступлениям автора из той или иной страны;
*   Используйте фильтр по количеству топ-областей деятельности авторов в верхней правой части дашборда "Авторы выступлений";
*   Используйте легенды, чтобы фильтровать данные, отражаемые на визуализациях;
*   Наводите курсор на графики и схемы, чтобы увидеть детали.
